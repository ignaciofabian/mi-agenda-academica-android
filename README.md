📚 Mi Agenda Académica - Android

📌 Descripción

Mi Agenda Académica es un proyecto de aplicación móvil para Android, desarrollado como parte de mi aprendizaje en Ingeniería en Informática en Duoc UC.

El objetivo del proyecto es practicar el desarrollo de aplicaciones Android utilizando Kotlin y Jetpack Compose, aprendiendo a crear interfaces modernas, organizar componentes y trabajar con navegación básica.

🛠️ Tecnologías utilizadas

Kotlin: lenguaje de programación principal.

Jetpack Compose: creación de interfaces gráficas.

Android Studio: entorno de desarrollo.

Gradle: gestión y compilación del proyecto.

Git y GitHub: control de versiones y almacenamiento del código.

🎯 Objetivos de aprendizaje

Comprender la estructura de un proyecto Android.

Crear interfaces utilizando Jetpack Compose.

Aprender a utilizar componentes reutilizables.

Practicar la navegación entre pantallas.

Mejorar la organización y comprensión del código.

Familiarizarme con el uso de GitHub.

🚀 Cómo ejecutar el proyecto

Descargar o clonar el repositorio.

Abrir el proyecto en Android Studio.

Sincronizar las dependencias con Gradle.

Seleccionar un emulador o dispositivo Android.

Compilar y ejecutar la aplicación.
